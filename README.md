# Aldekaa Co. website

A responsive Arabic/English company website for Aldekaa Co., built with plain HTML, CSS and JavaScript. No build step, backend, or paid service is required.

## Run locally
Open `index.html` in a browser.

## Deploy to Render (free Static Site)
1. Create a GitHub repository and upload all files in this folder.
2. Sign in at https://render.com and choose **New + → Static Site**.
3. Connect the GitHub repository.
4. Use these settings:
   - **Name:** aldekaa-company
   - **Branch:** main
   - **Root Directory:** leave blank
   - **Build Command:** leave blank
   - **Publish Directory:** `.`
5. Click **Create Static Site**. Render will provide a free `*.onrender.com` address.

The included `render.yaml` can also be used as a Blueprint configuration.
